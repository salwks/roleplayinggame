# 설화록 (Seolhwarok)

조선시대를 기본 현재시점으로 하는 **설화 개입형 오픈월드 RPG** 기획 저장소.

## 핵심 원칙

> 설화는 읽는 것이 아니라 겪는다.
>
> 『설화록』은 이야기를 수집하는 책이 아니라 플레이어가 겪은 이야기가 남는 책이다.

- 조선이 기본 현재시점이다.
- 신라·백제·고구려·고려 등 이전 시대 설화는 **혼·꿈·빙의·장소의 잔향**을 통해 직접 플레이할 수 있다.
- 신화·무속적 존재는 **조선 현재에도 현현하여 작동**할 수 있다.
- 원작 주인공의 핵심 선택과 결말을 플레이어가 빼앗지 않는다.
- 플레이어는 조사·호위·잠입·전투·생활·의식 등 자기 역할을 수행한다.
- 기록은 콘텐츠가 아니라 플레이 결과다.
