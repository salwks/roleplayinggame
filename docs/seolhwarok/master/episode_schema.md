# Episode File Schema

각 에피소드 파일은 아래 필드를 기준으로 누적한다.

1. ID / 표준 설화명 / 부제
2. 원전 계열 및 검증 상태
3. 지역
4. 원전 시대
5. 게임 시점: 현재 / 잔향 / 현현 / 혼합
6. 등급: A / B / C / D / W
7. 예상 플레이타임
8. 원전 핵심 사건
9. 절대 변경하지 않을 요소
10. 플레이어 역할과 개입 한계
11. 전체 플레이 플로우
12. 대사 스크립트
13. 공통 Gameplay Module
14. 시그니처 서브게임
15. 선택지와 결과
16. 실패/성공 처리
17. 핵심 신물·보상
18. 월드 변화
19. 다른 설화 연결
20. 『설화록』 기록문
21. 개발 메모 / 제작 난이도
22. 원전 추가 검증 TODO
