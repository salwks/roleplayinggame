# 공통 Gameplay Module

118개 설화마다 완전히 독립된 미니게임을 만들지 않는다. 공통 모듈을 조합하고 필요한 설화에만 시그니처 서브게임을 얹는다.

| 코드 | 모듈 | 설명 |
|---|---|---|
| INV | 조사 | 현장, 단서, 증언, 장부, 모순 대조 |
| SOC | 사회 | 대화, 설득, 재판, 거짓말, 협상 |
| STL | 잠입 | 잠입, 미행, 위장, 은닉 |
| TRK | 추적 | 추적, 사냥, 흔적 읽기 |
| CBT | 전투 | 근접전, 보스전, 생존전 |
| MOV | 이동 | 등반, 항해, 도주, 생존 이동 |
| PUZ | 퍼즐 | 환경, 논리, 장치, 공간 퍼즐 |
| RIT | 의식 | 굿, 제사, 금기, 천도, 신앙 행위 |
| GAT | 채집 | 약초, 채집, 제작, 치료 |
| ESC | 호위 | 구출, 호위, 운송, 동행 보호 |
| ECO | 경제 | 장사, 흥정, 자원, 물자 관리 |
| TIM | 타이밍 | 리듬, 공연, 신호, 균형, 정확한 순간 행동 |
| ECH | 잔향 | 꿈, 빙의, 과거 기억, 시대 전환 |
| ART | 신물 | 신물, 변신, 초자연 특수능력 |
| LIFE | 생활 | 농사, 건축, 노동, 잡역, 생업 |

## 시그니처 서브게임 예시

씨름, 저포, 배 조종, 베짜기, 성쌓기, 굿, 처용무, 풍수, 도술, 출산 의식, 장사, 낚시 등.

시그니처 게임은 '미니게임을 넣기 위해' 추가하지 않는다. 원전의 행동을 실제 플레이로 번역할 때만 사용한다.
